# Self-Hosted Map Assets & Credits

This directory contains pre-built sprite sheets (`maki.json`, `maki.png`, `maki@2x.json`, `maki@2x.png`) served locally by LovedOnes for MapLibre POI rendering:

- **POI Icons — Mapbox Maki (`@mapbox/maki` v8.2.0):**
  - Source: <https://github.com/mapbox/maki>
  - License: **CC0 1.0 Universal (Public Domain)** — see [`MAKI_LICENSE.txt`](MAKI_LICENSE.txt).
  - Bundled into `1x` and `@2x` sprite sheets using [`spreet`](https://github.com/flother/spreet) (MIT License) with category-colored circular badges.
- **Map Fonts — Plus Jakarta Sans:**
  - Source: <https://github.com/tokotype/PlusJakartaSans>
  - License: **SIL Open Font License 1.1** — see [`../fonts/OFL.txt`](../fonts/OFL.txt).
- **Vector Map Data Schema:**
  - Compatible with **OpenStreetMap** data (<https://www.openstreetmap.org/copyright>, ODbL) via **Protomaps** regional `.pmtiles` builds (<https://protomaps.com>).
